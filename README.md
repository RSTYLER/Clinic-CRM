# Clinic Management System (WinForms, C#)

## Описание проекта

Данное приложение представляет собой информационную систему поликлиники, разработанную на языке C# с использованием технологии Windows Forms.

Система предназначена для учета пациентов, врачей, заболеваний, а также для анализа финансовых показателей (доходы, расходы, прибыль).

## Основной функционал

* Учет пациентов
* Учет врачей
* Управление отделениями
* Хранение информации о заболеваниях
* Расчет стоимости лечения
* Подсчет доходов и расходов

## Архитектура

В проекте используется разделение на слои:

* **Models** — классы сущностей (Patient, Doctor, Disease и др.)
* **Data (Repository)** — работа с базой данных
* **UI (WinForms)** — пользовательский интерфейс

## Используемые технологии

* C#
* .NET 8
* Windows Forms
* SQL Server / SQLite
* Entity Framework Core (опционально)

## Структура базы данных

База данных включает следующие основные таблицы:

* Patients
* Doctors
* Departments
* Diseases
* Treatments

## Назначение

Система может быть использована для автоматизации работы поликлиники и упрощения учета медицинских данных.
